# Week 2 assignment: Setting up Claude Code

## What to do

Follow the [week 2 README](README.md) on your own laptop, then collect four things.

**(a) Installed.** A screenshot of your terminal after you run `claude --version`, showing the version number followed by `(Claude Code)`.

**(b) First session.** A screenshot of your first session showing a permission prompt: the moment Claude Code asks you to approve creating `hello.md` (or another action). The choices (Yes, No and so on) should be visible.

**(c) Your CLAUDE.md.** Copy and paste the text of `~/my-first-project/CLAUDE.md`, including your three preferences. To get the text, open the folder as in step 4j of the README (`open .` on a Mac, `explorer.exe .` on Windows) and open `CLAUDE.md` in a text editor, or ask Claude Code "Show me the contents of CLAUDE.md" and copy it from the terminal.

Make the preferences **meaningful**: specific, and about how you want Claude Code to work with you (how you like explanations, what it must check with you first, how long answers should be). Filler like "Be helpful" or "Do a good job" doesn't count. The README's examples are fine; your own are better.

**(d) One short paragraph** on the permission prompt: which prompt you saw (what did Claude Code want to do?), what you chose, and why. Would you have chosen differently if it had wanted to delete a file, or work outside your project folder?

Never include a password, an API key or your sign-in code in a screenshot. If one is visible, crop it out.

## What to hand in

- One document with the two screenshots, the text of your CLAUDE.md and your paragraph.

## Rubric

| Criterion | Points |
|---|---|
| Claude Code is installed and running: 2 points for the `claude --version` screenshot, 2 points for the permission prompt screenshot | 4 |
| CLAUDE.md with three meaningful preferences (specific, about how Claude Code should work with you, not filler) | 3 |
| The permission paragraph shows you understood what you approved | 3 |
