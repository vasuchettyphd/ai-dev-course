# Week 3 assignment: Git and GitHub

## What to do

Follow the [week 3 README](README.md) on your own laptop, then collect three things.

**(a) Your private repo.** The address of your GitHub repo, for example `https://github.com/yourusername/my-first-project`. It must be **private**, and `vasuchettyphd` must be added as a collaborator (step 9 of the README). Your instructor accepts the invitation from the email GitHub sends, then checks the repo. Don't make the repo public.

**(b) A merged pull request.** The address of a pull request in that repo that you merged into `main`, for example your `add-goals` PR from step 7. Its title should say what changed, and its description should say what changed and why, in a sentence or two. If Claude Code's first title or description was vague, edit them on GitHub before you hand in.

**(c) A short reflection, one paragraph.** When would you use a branch? Describe one real situation from your project, studies or work where you'd make a change on a branch and a pull request instead of changing `main` directly. Say what could go wrong without the branch, and how you would undo a bad change once it was committed.

Never put a password, a sign-in code or a token in your hand-in.

## What to hand in

- One document with the repo address, the pull request address and your paragraph.
