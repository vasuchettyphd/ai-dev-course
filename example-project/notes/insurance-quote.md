# Insurance quote for a rental

Fictional notes written for this course example; no real people or addresses.

A landlord policy costs more than a homeowner policy on the same house. The agent quoted a premium of $1,350 a year for a $150,000 brick ranch, with a $1,000 deductible.

The premium went up by about $200 when I asked for loss of rent cover, which pays the rent for a few months if a fire makes the house unlivable. I think that cover is worth it.
