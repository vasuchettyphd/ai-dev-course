# ShelfSwap: a made-up student startup

This is the plain-English description you hand to Archify in Step 3. No code exists for it. Edit it into your own idea if you like.

ShelfSwap lets UVU students sell used textbooks to each other on campus.

1. A seller snaps a photo of the book's barcode in the ShelfSwap web app.
2. ShelfSwap looks up the title and the new price from a book database, and suggests an asking price of 40% of new.
3. The seller can accept the price or change it, then the listing goes live.
4. A buyer searches by course code (for example ACC 2010) and sees the listings for that course.
5. The buyer pays in the app with a card. ShelfSwap holds the money; it does not go to the seller yet.
6. Buyer and seller meet at the library hand-off shelf. The buyer scans a code on the seller's phone to confirm they have the book.
7. Only then is the money released to the seller, minus a 10% ShelfSwap fee.
8. If nobody confirms within 7 days, the buyer gets a full refund and the listing goes back up.
